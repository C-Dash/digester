# CDASH Digester — Project Briefing

## What This Is

A PySide6 desktop application that validates, prescreens, and catalogs archival media batches for the CDASH (Cambridge Digital Architectural Survey History) system. It processes batch folders of JPEG, TIFF, and PDF files, checks them against acceptance criteria, and exports CSV catalogs.

## Project Layout

```
src/
  cdash_digester/
    cdash_objects.py     — SQLite data model (BatchDB), name parsers, constants
    digester.py          — Main orchestrator (Digester class); runs on QThread
    prescreener.py       — Per-file acceptance checks; screen_file() is the core function
    repair_media.py      — Auto-repair for known fixable issues (rgba, iphone_vert)
    validator.py         — CDASHValidator for folder/media name rules
    gui/
      main_window.py     — Top-level PySide6 window and toolbar actions
      folder_pane.py     — Left pane: item set folder tree
      media_table.py     — Right pane: media file table with status columns
      thumbnail_pane.py  — Thumbnail preview
      console_window.py  — Log output window
    exif_ex.py           — CLI: dump all ExifTool tags for a file
```

## Naming Conventions

- **Batch folder**: `CDB<YYMMDD>[a-z]?-<name>` (e.g. `CDB260320-Test_batch`)
- **Media folder**: `[F<index>-]<slug>-OF<item_set_id>` (e.g. `F6-Mass_Ave-OF43111`)
- **Media file stem**: `<place_slug>_<doc_index>p<page_index>-<doc_type>[-OP<place_id>]`
  - e.g. `Mass_Ave_0027p0001-VE-OP43296`
- **Doc types**: 2-letter codes — VE (Exterior View), VI (Interior View), RF (Research Form), AI (Architectural Inventory), VP (Plan View), and others — defined in `cdash_objects.DOC_TYPES`

## Batch Folder Structure

```
CDB<date>-<name>/
  Media/
    <media-folder>/
      *.tif / *.jpg / *.pdf
  Catalog/
    batch_db.sqlite      — generated by digester
  Rejects/
    <media-folder>/      — copies of rejected files
    orig/                — originals backed up before repair
    rejects.csv
```

## Data Model (SQLite via BatchDB)

Key tables: `cdash_item_sets`, `cdash_media`, `cdash_rejects`

`cdash_media` important columns:
- `ready` INTEGER (0/1) — whether file passed prescreening
- `repair_issues` TEXT — comma-separated issue codes (e.g. `"multiframe_tiff, rgba"`)
- `notes` TEXT — human-readable qa_note from prescreener

## Prescreener Acceptance Criteria

| Format | Rules |
|--------|-------|
| JPEG | 24-bit RGB, ≤ 100 MB, ≤ 108 MP |
| TIFF | 24-bit RGB or 8-bit grayscale (L), LZW compression (tag 259 = 5), single-frame |
| PDF | Accepted; logs if PDF/A-1b conformance marker is absent |

## Repair Issue Codes

| Code | Meaning | Auto-repairable? |
|------|---------|-----------------|
| `rgba` | Image is RGBA mode | Yes — composited onto white RGB |
| `iphone_vert` | iPhone portrait TIFF needing rotation | Yes — rotated via EXIF Orientation |
| `multiframe_tiff` | TIFF contains > 1 frame | **No** — must be handled manually |

Issue codes are normalized: lowercase, hyphens → underscores. The `multiframe_tiff` issue is always inserted first in the list.

## Key Entry Points

- **GUI**: `cdash-digester` (script) or `python -m cdash_digester.gui.main_window`
- **Digester CLI test**: `python -m cdash_digester.digester`
- **Prescreener CLI** (inspect a single file): `python -m cdash_digester.prescreener <filepath>`
- **Repair CLI**: `python -m cdash_digester.repair_media <filepath> <issue_code> [...]`

## Key Dependencies

- `PySide6` — GUI framework
- `Pillow` — image reading, mode checks, frame counting, repair transforms
- `PyMuPDF (fitz)` — PDF metadata and XMP parsing
- `exiftool` (external executable, called via one-shot subprocess in `exiftool_util.read_tags`) — EXIF Orientation, HostComputer, DateTimeOriginal

## Development Notes

- ExifTool must be on PATH for EXIF reads to work.
- Repair backs up originals to `Rejects/orig/` before overwriting.
- The GUI runs `Digester` methods on a `QThread`; the `log` callback is the only UI coupling.
- `repair_file()` in `repair_media.py` must never attempt to repair `multiframe_tiff` — it returns early with an error message.
